JavaScript na AgroFeira

Nesta atividade, coloquei em prática as três formas de usar JavaScript numa página: a externa (ligando um arquivo .js pelo src), a interna (escrevendo o código entre as tags script) e a em linha (colocando o código direto no atributo onclick de um botão).

Decisão de estilo (Atividade 6)

Reler a minha decisão de estilo da Atividade 6 foi importante para perceber que ela não muda com a chegada do JavaScript. Os tokens e as camadas de CSS que eu defini continuam válidos. O que muda é apenas onde o estilo é aplicado: no site estático ele fica no repositório, e nos componentes do CodeSandbox eu reaproveitei as mesmas cores do tokens.css.
